# XEmail 用户使用说明书

XEmail 是一款带有 **AI 智能分类** 和 **AI 草稿生成** 的多账号邮件客户端。除了能像普通邮箱一样收发邮件，它最大的特点是 **会随着你的使用越来越懂你**：每一次「标重要 / 取消重要」、每一次「改分类」，系统都会问你"为什么"，并把你的理由沉淀成一条经验，让以后类似邮件能被自动正确处理。

本说明书面向**所有用户**，并在结尾单列一节给在本机自托管 XEmail 的人（你需要会启动 / 关闭后端进程）。管理员专属的「系统模式」「用户管理」「DeepSeek API Key 设置」等不在此说明。

---

## 0. 启动与关闭系统（自托管时）

XEmail 的后端是一个本地服务进程。**只要它在跑，你和你授权的用户就能用浏览器访问 `http://127.0.0.1:8000`**。它不在跑，所有页面都打不开。

如果你只是普通使用者、由别人帮你托管这套系统，可以跳过本节，直接看第 1 节登录。

### 0.1 启动后端：双击 `scripts/start.command`

在项目目录里打开 `scripts/` 文件夹，**双击 `start.command`**。会弹出一个 Terminal 窗口，提示信息大致如下：

```
================ XEmail 启动 ================
项目目录 : /Users/<you>/Documents/Workspace/XEmail
监听地址 : http://127.0.0.1:8000
日志文件 : /Users/<you>/Documents/Workspace/XEmail/data/server.log

[环境] 使用虚拟环境: .../.venv/bin/python
[启动中] 正在后台启动 uvicorn ...
[完成] PID=12345
浏览器即将打开 ...
（本窗口可以直接关闭，后端会继续运行）
```

看到「本窗口可以直接关闭」之后，**把这个 Terminal 窗口关掉也没关系**——后端通过 `nohup` 已经脱离了它，会继续在后台运行。浏览器同时会自动打开主页。

第一次双击如果 macOS 提示「无法打开，因为它来自身份不明的开发者」，去【系统设置 → 隐私与安全性】里点「仍要打开」即可（之后就不会再问）。

启动脚本会自动检测：
- 端口 8000 是否已经被占用（被其它程序占用会拒绝启动）
- 是否已经有一个 XEmail 实例在跑（已有则直接打开浏览器，不会重复启动）
- `.venv` 虚拟环境是否存在；没有则用系统 `python3`，并提示你按 README 装依赖

如果启动失败，日志在 `data/server.log`。

### 0.2 关闭后端

有两种方式，按方便程度从高到低：

1. **管理员页面里的「关闭后端」按钮（推荐）**。登录管理员账号，点右上角「⚙ 设置」旁边的【用户管理】链接（或直接访问 `/admin`），在「后端服务」卡片里点 **「关闭后端」**。系统会要求二次确认，确认后几秒内后端进程退出，所有浏览器页面也会随之失效。
2. **双击 `scripts/stop.command`**。即使你的浏览器关了、忘了密码登不进管理员页，这种方式始终可用。脚本会先尝试用 PID 文件优雅地停止进程，停不住再强制结束。

> 关闭后想再开起来，回到 0.1 节双击 `start.command` 即可。

### 0.3 一些常见情况

| 现象 | 怎么办 |
|---|---|
| 浏览器打不开 `http://127.0.0.1:8000`，提示「无法访问」 | 后端没启动。双击 `scripts/start.command`。|
| 双击 `start.command` 提示「端口 8000 已被其它程序占用」 | 先双击 `stop.command` 关闭旧实例；如果不是 XEmail 占用的端口，则改用其它端口（在终端 `XEMAIL_PORT=8001 scripts/start.command`）。|
| 管理员页点「关闭后端」之后想立刻再打开 | 等几秒，后端完全退出后再双击 `start.command`。|
| 我希望开机自动启动 | 当前脚本是手动启动模式。如果你希望开机即可用，可考虑配置 macOS LaunchAgent（不在本说明范围）。|

## 1. 登录

打开网址 → 输入用户名和密码 → 进入主页。账号由管理员创建，初始密码也由管理员告知，第一次登录后可在「设置」里修改。

## 2. 配置自己的邮箱账号

第一次使用，进入 **⚙ 设置**（右上角）→ **+ 新增账号**：

- 「**账号名称**」是给自己看的标签，例如"工作 Gmail"
- 「**发件邮箱 / 邮箱密码**」要填**授权码**，不是网页登录密码（QQ / 163 / Gmail 都需要在邮箱网页端单独生成授权码）
- 「**SMTP / IMAP**」按邮箱服务商的官方说明填，常见的网易、QQ、Gmail 都已经预填好默认值
- 「**邮件落款**」可填可不填，写新邮件和回复时会自动追加在正文末
- 「**服务器同步**」决定本地操作（已读、删除、改分类等）是否同步回服务器；不确定就保持默认
- 保存后可点「**连接诊断**」一键测试 SMTP/IMAP 是否通

支持加多个账号，主页左上角下拉框一键切换 **激活账号**。

## 3. 普通邮件功能（一句话带过）

撰写 / 回复 / 全部回复 / 转发（含抄送 Cc、暗送 Bcc、多附件、HTML 与纯文本切换）、草稿箱、已发送、收件夹、回收站、置顶、标记未读 / 已读 —— 跟你用过的任何邮箱客户端没有区别，直接用即可。

下面是真正不一样的地方。

## 4. ⭐ 核心特色一：AI 智能分类（自动）

每次点 **「收取邮件」**，系统会：

1. 用 **IMAP 增量协议** 只拉取上次收取之后的新邮件 —— 不重复下载，不浪费 AI 配额
2. 对每封新邮件**自动判断分类**（工作 / 账单 / 营销 / 社交 / 其他 / 你自己建的分类…），用 DeepSeek 大模型完成
3. 落入对应文件夹；判断不出来的进「未分类」

界面会实时显示进度（"已分类 5/20：[账单] 美团发票"）。

**为什么这跟别的邮箱不一样**：传统邮箱要么没分类要么只能写死规则；XEmail 用 AI 理解邮件语义，并且**会学习你的偏好**（见下文 5、6 节）。

> 提示：每选中一封邮件，状态栏会显示 **"分类「X」· 原因：…"**，告诉你 AI 当时为什么这么判断，方便你审查。

---

## 5. ⭐ 核心特色二：标「重要」时会问你为什么

在邮件详情页点 **☆ 标为重要** 或 **★ 取消重要** 时，**不会立刻执行**，而是弹出一个对话框：

- 顶部展示这封邮件的主题 / 发件人
- 让你填写**为什么这封邮件重要 / 不重要**

填完点击「**标为重要并记录经验**」后，系统会：

1. 切换重要标记
2. 把你的理由（结合邮件内容）**让 AI 提炼成一条通用经验**，例如：
   > "来自导师邮箱、主题含明确截止日期的邮件应标为重要。"
3. 这条经验存入右侧「💡 经验」分区，**以后类似邮件 AI 都会参考这条经验做判断**

**写理由的小技巧**：尽量描述**邮件特征**（发件人、主题词、正文模式），而不是这一封邮件的具体内容，这样经验更容易复用。

弹框里一共有三个按钮：

- 「**标为重要并记录经验**」/「**取消重要并记录经验**」：上面说的完整流程。
- 「**直接标为重要**」/「**直接取消重要**」：只切换标记，**不沉淀经验**。适合一些一次性的、不希望让 AI 推广到其它邮件的场景。
- 「**取消**」：什么都不做，回到原样。

---

## 6. ⭐ 核心特色三：改变分类时也会问你为什么

把邮件**拖拽**到另一个文件夹、或在详情页用 **「📁 移动到 ▾」** 选另一个分类时，也会弹出"为什么归到这个分类？"的对话框。流程跟「重要」完全一样：

1. 你填理由
2. AI 提炼成一条**通用、明确指向目标分类**的经验，例如：
   > "来自财务系统、主题含 invoice/账单 字样的邮件应归入「账单」。"
3. 以后**新邮件直接被分到这个分类**，不用再手动调整

弹框里同样三个按钮：

- 「**移动并记录经验**」：上面的完整流程。
- 「**直接移动**」：只把邮件挪过去，**不沉淀经验**。适合个别特例（只是当前这封不属于原分类，但不希望 AI 推广到类似邮件）。
- 「**取消**」：什么都不做，邮件留在原分类。

> 这是 XEmail 最关键的设计：**让"纠正"成为系统学习的契机**，而不是无谓的体力劳动。但「直接执行 / 直接移动」这条逃生通道也保留着——遇到特例不必勉强写理由。

## 7. ⭐ 核心特色四：AI 起草邮件正文

### 7.1 自动回复

回复邮件时，撰写窗口里会出现「**✨ 自动回复（实验性）**」面板：

1. 在文本框里告诉系统**你想回什么**（用大白话）
   > 例："礼貌确认收到、同意周三下午开会，并请对方发来议程。"
2. 点「✨ 生成回复」—— DeepSeek 帮你起草一封完整的回复，**自动匹配原邮件语言**（来信是英文就回英文，中文就回中文）
3. 自动追加你的账号签名
4. 生成后你还可以自由编辑再发送

### 7.2 自动撰写新邮件

点撰写新邮件，撰写窗口里有「**✨ 自动生成（实验性）**」面板，用法一样：告诉系统你要写什么，AI 起草正文。

### 7.3 来信摘要（仅英文邮件）

回复一封英文邮件时，撰写窗口顶部会自动出现「**📝 来信摘要**」—— 用两句中文概括「邮件大意」和「对方诉求」，方便你在动笔回复之前快速 grasp 来信内容。中文邮件不会触发，避免冗余。

---

## 8. ⭐ 核心特色五：携带原邮件附件

回复一封带附件的邮件时，撰写窗口顶部会出现一条横幅：

> 原邮件含 2 个附件，是否一起带上？ **[携带]** **[忽略]**

点「**携带**」即可一键把原邮件的附件复制到你的回复里，不用自己下载再上传。

## 9. 重要邮件置顶 + 全部视图

左侧栏顶部固定了两个跨文件夹的视图：

- **⭐ 重要**：所有**待处理**的重要邮件——被标为重要但还没点过「✓ 已处理」。
- **✓ 曾经重要**：已经点过「✓ 已处理」的重要邮件。它们的"重要"标记保留着，所以经验系统知道它们当时为什么重要；但它们不再出现在 ⭐ 重要 列表里，避免干扰你处理新邮件。
  > 想撤销「已处理」？目前的简单做法：在邮件详情页点「★ 取消重要」（会同时清掉"已处理"），然后再点「☆ 标为重要」即可重新进入 ⭐ 重要 列表。

往下还有 **「✦ 全部」**——所有未删除邮件。

每个邮件文件夹后面有两种小徽章：
- **蓝色** —— 未读数量
- **红色（带 ★）** —— 该文件夹里**待处理**的重要邮件数量（已处理的不再计数）

## 10. 多账号一键切换

主页左上角的下拉框列出了你所有邮箱账号。点选任一账号，整个界面（左侧文件夹、邮件列表、智能分类的提示规则）都会切换到那个账号上下文。

不同账号的**分类规则、提示、经验互相隔离**，互不干扰。

## 11. 进阶：管理你的分类规则（右侧栏）

右上角的 **「◧ 提示栏」** 按钮可以显示/隐藏右侧的"智能分类提示栏"。它分四块，从优先级高到低排列：

| 区块 | 干什么的 | 谁创建 |
|---|---|---|
| **🛠 系统** | 全局基础指引，告诉 AI 总体怎么判断 | 管理员维护（你只读） |
| **⚙ 固定规则** | 命中即停的硬规则，本地代码执行，不走 AI（最快、最确定） | 你自己写 |
| **💬 提示** | 用自然语言写的偏好，作为 AI 的上下文 | 你自己写 |
| **💡 经验** | 从「标重要 / 改分类」对话中自动沉淀；也可手动编辑 | 自动 + 你手动 |

四个区块都可以单独折叠。每个区块每条记录可以查看 / 编辑 / 删除。

### 11.1 固定规则

固定规则是**最确定的分类方式**：用自然语言描述一条规则（"发件人含 @example.com 且主题含'通知'，归入「学校」"），系统会把它翻译成一段程序，**本地执行**。一旦命中，**直接落入指定文件夹，不再询问 AI**。

适合：你 100% 确定能写死的规则。例如：
- "来自 noreply@github.com 的邮件归入「开发」"
- "主题以「Re:」开头且收件人只有我的邮件，标为重要"

规则**按从上到下顺序匹配**，可用 ▲▼ 按钮调整顺序。第一条命中就停。

### 11.2 提示（Prompt）

不用写规则的硬条件，**直接用大白话**告诉 AI 你想怎么分类：

> "凡是来自 @alipay.com 或 @tenpay.com 的邮件，都归入「账单」。"

提示可以指定**目标文件夹**（系统按这个分类）或不指定（仅作为 AI 的通用判断指引）。

### 11.3 经验（Experience）

经验**主要由系统自动生成**（见前文 5、6 节），但你也可以：

- **手动添加**：在「💡 经验」下方的输入框里写
- **编辑**：把自动生成的经验改得更准确
- **删除**：不再想要的经验直接删

每条经验会显示它的**来源标签**：
- `★ 标为重要` / `☆ 取消重要` —— 从「重要」对话框沉淀
- `📁 改分类` —— 从「改分类」对话框沉淀
- `✍ 手动` —— 你自己写的

## 12. 实时收取进度

点击「**收取邮件**」后，状态栏会显示：

- "已连接邮箱，正在搜索…"
- "服务器有 N 封新邮件待处理…" / "没有新邮件"
- "已分类 5/20：[账单] 美团发票"（每封实时刷新）
- 收取完毕汇总："共收取 N 封，新增 K 封"

支持**临时覆盖**单次收取数量：toolbar 上「数量」输入框填一个 1–200 的整数即可；留空则用账号设置里的默认值（首次使用建议设小一点 5–20，跑通后再放大）。

## 13. 设置面板里其他常用项

进入 **⚙ 设置**，向下滚：

- **邮件落款**：每个账号独立，自动追加；编辑草稿时不重复追加
- **服务器同步**：决定本地操作是否回写到 IMAP 服务器
  - 已读 / 已回复（`\Seen` / `\Answered`）
  - 已删除（`\Deleted` + EXPUNGE）
  - 文件夹（MOVE 到对应 mailbox）
  - 不同邮箱服务商支持程度不同，遇到问题先关掉，邮件依然能正常收发
- **每次收取邮件数量**：默认 20，可在 1–200 之间调整

## 14. 常见问题

**Q：为什么我刚收取的邮件分类是「未分类」？**  
A：可能是 AI 在那一刻不可用（API Key 未配置 / 网络抖动）。等管理员配好 Key 后，可以点击工具栏的「🧠 智能分类」按钮把「未分类」里的邮件重新跑一遍 AI 分类。

**Q：分类错了怎么办？**  
A：直接把它**拖到正确的文件夹**，或在详情页用「📁 移动到 ▾」选目标分类，在弹框里写为什么——以后类似邮件就会自动正确分类。

**Q：标重要 / 改分类时的弹框可以关掉吗？**  
A：可以点「取消」完全跳过这次操作。如果只是想**执行这次但不沉淀经验**，点新加的「**直接标为重要 / 直接取消重要 / 直接移动**」按钮——操作照做，只是不写新经验。**但强烈建议大多数情况下都填理由**，这是让系统变聪明的唯一途径；逃生按钮仅用于一次性特例。

**Q：固定规则、提示、经验三者的优先级是什么？**  
A：固定规则 > 提示 / 经验（一起喂给 AI 作判断）> 系统默认规则。固定规则命中就停，不会再问 AI。

**Q：能用浏览器多开多个账号同时操作吗？**  
A：同一台浏览器同时只能登录一个用户。但同一个用户名下可以有多个邮箱账号，用左上角下拉框切换。

**Q：附件最大多大？**  
A：单个附件上限 25 MB。

**Q：忘记密码？**  
A：找管理员重置即可。

## 15. 快速上手清单

如果你只想立刻能用：

1. ✅ 登录 → 进「⚙ 设置」加邮箱账号 → 测试连接通过
2. ✅ 回主页点「收取邮件」，看 AI 把邮件分到各文件夹
3. ✅ 遇到分到错文件夹的邮件，**拖到正确的文件夹 + 填理由**
4. ✅ 看到值得标重要的邮件，**点 ☆ + 填理由**
5. ✅ 反复 3 和 4，几天之后系统的分类准确率会显著提升

回复邮件时，如果懒得自己写，试试撰写窗口里的「**✨ 自动回复**」。

祝使用愉快。
